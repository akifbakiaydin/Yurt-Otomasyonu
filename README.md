# 🏢 Dormitory Management System (Yurt Otomasyonu)

Desktop application for managing a student dormitory — student registration, room occupancy, payments, expenses and income statistics — backed by a Microsoft SQL Server database.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![.NET Framework](https://img.shields.io/badge/.NET_Framework-WinForms-512BD4?style=flat-square)
![SQL Server](https://img.shields.io/badge/SQL_Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white)

---

## ✨ Features

- **Admin login** and admin management panel
- **Students** — register, edit, delete, list and report
- **Rooms & departments** — room occupancy tracking, department management
- **Payments** — student debt and payment screen
- **Expenses** — add, update and list dormitory expenses
- **Income statistics** overview
- **Staff** management and notes

## 🛠️ Tech stack

| Layer | Technology |
|---|---|
| UI | C# Windows Forms |
| Data | Microsoft SQL Server, ADO.NET typed DataSets |
| IDE | Visual Studio |

## 🚀 Running the project

1. Open `Yurt kayıt sitemi/YurtKayitSistemi.sln` in Visual Studio.
2. Create a SQL Server database named `YurtOtomasyon`.
3. Update the connection string in `SqlBaglantim.cs` to point to your SQL Server instance.
4. Build and run.
